# @cl/browser-extension

## 1.1.0

### Minor Changes

- 2187c25: 設定に「このアプリについて」を追加しました。バージョン、為替レートの提供元、ライセンス、ソースコードとプライバシーポリシーへのリンク、ストアのレビューページへのリンクを確認でき、拡張機能に含まれるオープンソースソフトウェアのライセンスも一覧で見られます。
- e0c3e19: 「5万円」「3億5000万円」「$1.5 million」「€3 Mio.」のように、万・億や million などの単位を使った金額も換算できるようにしました。日本語、中国語、韓国語、英語、ドイツ語、フランス語、スペイン語、ポルトガル語、イタリア語、オランダ語、ロシア語、ポーランド語、トルコ語、インドネシア語、ベトナム語、タイ語、ヒンディー語、アラビア語の主な単位に対応しています。

  「価格は500円です」のように前後に日本語などが続く金額と、「5万ドル」「10万ユーロ」のように日本語の通貨名で書かれた金額も換算できるようにしました。

- 6b9116b: 為替レートのグラフで使う上昇と下落の色を選べるようにしました。

  - 設定の「外観」にある「チャートの色」で、上昇と下落を押すと、17色から色を選べます。「デフォルト」を押すと、既定の色（上昇は緑、下落は赤）に戻ります。
  - 選んだ色は、Popup とページ上の換算カードの両方で、レート画面のグラフと矢印、換算画面の推移のグラフに使います。換算カードを開いている間に色を変えた場合も、すぐに反映します。明るい色を選んでも文字が読みにくくならないよう、変化率の数字は通常の文字色のまま表示します。
  - 選んだ色は同じアカウントの別の端末にも同期します。

- cff14e7: 金額を選択すると、ボタンを押さなくても、登録した通貨のうち一番上の通貨での金額が国旗と一緒に表示されるようになりました。選択した金額と同じ通貨が一番上にある場合は、次の通貨で表示します。表示を押すと、これまでどおり登録したすべての通貨での換算カードが開きます。金額は数字が転がるように表示され、別の金額を選び直すと、増えれば上へ、減れば下へ転がって切り替わります。換算カードの金額も、表示するときに転がり込むようになりました。
- ad2957b: 画面の表示言語に、中国語（簡体字・繁体字）、韓国語、スペイン語、フランス語、ドイツ語、ポルトガル語（ブラジル）を追加しました。ブラウザの言語に合わせて切り替わります。あわせて、英語でレートを取得できなかったときの表示の誤記を直し、ページ上の換算カードを表示言語に合った字形で表示するようにしました。
- e82730e: 「99 Cent」「50 копеек」「50 centavos」「25銭」のように、各国語の補助単位で書かれた金額も換算できるようにしました。ユーロ圏の各言語、スイス、ロシア・ウクライナ・ベラルーシ、中南米、ポーランド、チェコ、トルコ、インドなどの補助単位と、日本円の銭、人民元の角・分に対応しています。「150円25銭」「3元5角2分」「12 руб. 50 коп.」のように主単位と続けて書かれた金額は、1件の金額として換算します。
- 292d1fe: 「50¢」「25 cents」「99 pence」のように補助単位で書かれた金額も、ドルやポンドに直して換算できるようにしました。「$5 and 50 cents」「£3 20p」のように主単位と続けて書かれた金額は、1件の金額として換算します。「¢」と「cents」は Popup で設定した `$` の解釈に従います。
- 8608395: Popup に為替レートの推移を表示するようにしました。

  - 画面上部の「換算｜レート」で、換算画面とレート画面を切り替えられます。レート画面の基準通貨は換算元の通貨と共通です。
  - レート画面では、換算後の通貨の推移を1日、5日、1か月、6か月、年初来（YTD）、1年の期間で表示します。「ALL」ではすべての通貨の変化率を重ねて、通貨を選ぶとその通貨のレートと期間中の変化を表示します。グラフにポインターを合わせるか矢印キーで動かすと、その時点の値を確認できます。
  - 換算画面の換算後の各通貨に、過去1か月の推移を小さなグラフで表示します。グラフを押すと、その通貨のレート画面を開きます。
  - 上昇は緑、下降は赤で表示します。
  - 履歴が欠けている区間はグラフに「データなし」と示し、表示する期間に履歴がまったくない場合はその旨を表示します。
  - ページ上の換算カードにも、Popup と同じ「換算｜レート」の切り替え、推移のグラフ、レート画面を表示します。レート画面の基準通貨はカードの換算元の通貨で、期間と通貨はカードを開くたびに1か月とすべての通貨に戻ります。カードが画面に収まらない高さになるときは、閉じるボタンと切り替えを残して、その下だけをスクロールします。

- e924a66: レートの時刻の横に、為替レートの提供元である Open Exchange Rates へのリンクを表示するようにしました。

### Patch Changes

- ef2b40e: 外観の設定で、テーマをシステム・ライト・ダークのボタンを並べたトグルで切り替えるようにしました。選んだボタンへ背景がスライドします。金額を選択したときに出るボタンも、ライトでは白、ダークでは濃いグレーで表示し、外観の設定に合わせるようにしました。あわせて、白い背景の上でも国旗の輪郭が分かるよう、国旗に薄い枠線を付けました。
- ab1bd41: 換算カードと設定画面の不具合を直しました。

  - 換算カードで換算先を編集しているとき、削除ボタンの説明が換算カードの後ろに隠れたり、表示が崩れたりしないようにしました。
  - 換算カードで金額を「10」から「10.0」のように同じ値へ書き換えたとき、読み込み中の表示のまま止まらないようにしました。
  - 「$」のように複数の通貨で使われる記号の設定で、「自動判定」を選べるようにしました。自動判定では、ページの言語から通貨を判断します。既定の通貨を選んだ場合も、ページの言語にかかわらずその通貨として読むようになります。
  - Popupで極端に大きな金額を入力したとき、画面全体がエラーにならず、換算できない通貨だけをその旨表示するようにしました。

- ae1535c: ストア検索で見つけやすくするため、拡張機能の名前に「Currency Converter」「通貨換算コンバーター」を入れ、短い説明を、価格を選択するだけで最大5通貨へ換算できることが一読で分かる文に改めました。README の Chrome Web Store リンクが誤った掲載 ID を指していた問題も修正しました。
- 21bb02d: ユーロを使う国にドイツとスペインが含まれていなかったため、ドイツやスペインのページで「50 cents」をユーロとして読めず、通貨の検索で「ドイツ」「スペイン」からユーロを見つけられませんでした。どちらも直しました。
- 012eb7a: インストールした直後にPopupや換算カードを開くと、「レートを利用できません」と表示されたまま換算できないことがありました。為替レートの最初の取得を待ってから換算するように直しました。
- 23d0d22: 換算結果の下のレートの時刻から「時点のレート」の文言を外し、提供元のリンクが途中で折り返さないようにしました。
