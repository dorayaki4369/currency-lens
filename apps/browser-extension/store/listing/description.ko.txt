Currency Lens는 읽고 있는 웹 페이지에서 바로 가격을 환산해 줍니다. 해외 쇼핑몰에서 쇼핑하거나 여행을 계획하거나 해외 뉴스를 읽을 때, ‘$19.99’, ‘€49’, ‘1,200 JPY’ 같은 가격을 선택하면 원하는 통화 최대 5개로 얼마인지 확인할 수 있습니다. 페이지를 벗어날 필요가 없고, 페이지 내용도 바꾸지 않습니다.

사용 방법

1. 웹 페이지에서 가격을 선택합니다.
2. 선택 영역 옆에 나타나는 Currency Lens 버튼을 누릅니다.
3. 작은 카드에 선택한 통화로 환산한 금액이 표시됩니다. 통화는 툴바에서 언제든 바꿀 수 있습니다.

기능

- 다양한 가격 표기 인식: 통화 기호($, €, ¥), 통화 코드(USD, JPY), 통화 이름(‘원’, ‘dollars’, ‘円’ 등)을 인식하며, ‘$1.5 million’, ‘5k円’, ‘5万円’ 같은 금액과 한국어, 일본어, 중국어, 태국어 문장 속 가격도 읽습니다.
- ‘$’처럼 여러 통화에 쓰이는 기호 처리: 설정, 페이지 언어, 브라우저 언어를 바탕으로 어떤 통화인지 판단합니다. 기호마다 어떤 통화로 볼지 바꿀 수 있습니다.
- 카드에서 다시 환산: 카드에서 바로 금액이나 원래 통화를 바꿔 다시 환산할 수 있습니다.
- 툴바 팝업: 금액과 통화를 직접 입력해 환산하고, 환산할 통화를 추가, 삭제하거나 순서를 바꿀 수 있습니다.
- Open Exchange Rates의 최신 환율을 사용하며, 환율이 오래되면 경고를 표시합니다.
- 한국어, 영어, 일본어, 중국어(간체·번체), 스페인어, 프랑스어, 독일어, 포르투갈어(브라질) 화면을 지원하며 브라우저 언어를 따릅니다.

개인정보 보호

계정이 필요 없습니다. 선택한 텍스트는 브라우저 안에서만 분석하며 어디에도 보내지 않습니다. 네트워크 요청은 환율을 가져올 때뿐이며, 페이지 내용은 포함하지 않습니다.
