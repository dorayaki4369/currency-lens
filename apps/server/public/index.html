Currency Lens

A currency converter that works right where you browse.

Currency Lens is a browser extension for Chrome and Firefox. Select a price or an amount on any web page, and it converts the amount in place into up to 5 currencies you register, without rewriting the page.

Get it for Chrome Get it for Firefox

Exchange rate API

This site, cl.dryk.net, serves the exchange rates the extension uses. The latest rates are available as JSON at GET /v1/latest. Rates are based on USD, sourced from Open Exchange Rates, and refreshed hourly.

Privacy

Text you select on web pages is analyzed only in your browser and is never sent to this API. See the Currency Lens Privacy Policy for details.
